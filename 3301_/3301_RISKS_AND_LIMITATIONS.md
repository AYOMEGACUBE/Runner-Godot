# 3301 Риски, ограничения и заметки аудита

**Актуально:** 2026-04-15. Объединяет бывшие `3301_RISKS.md`, `3301_LIMITATIONS.md` и краткое резюме `3301_TECHNICAL_AUDIT_REPORT.md`.

## Ограничения

- Primary sync в релизном контуре — RTDB (см. `3301_SYNC_PROTOCOL.md`).
- На **Android/iOS** выполнение git-команд sync, как правило, **отключено** в коде.
- **Offline-очереди** повторов sync нет: неуспех требует явного повторного действия пользователя/логики.
- **FileLogger:** при очень частых `FileLogger.log` растёт объём записи; `flush` выполняется периодически (~2 с), не на каждую строку — при экстремальном логировании возможны пики I/O.
- **First-buyer merge** зависит от корректности системного времени на клиентах.
- Статусы **`conflict`** в данных есть; UX-индикация может быть недостаточной (см. `3301_TODO_LIST.md`).
- Нет единой панели **метрик качества** генерации пути (reject rate, trend) в продакшене.
- **Два режима пути** (`use_path_leg_streaming`): легко ожидать чанки при выключенном флаге — тогда используется только `path_library_50.json`.
- **PathManager:** при пустом результате пребилда следующего колена возможен **тихий** выход без `push_error` — игрок остаётся без нового колена.
- **Стена — JSON:** один вызов `JSON.parse_string` на весь файл всё ещё выполняется в **одном** кадре; снят фриз за счёт поэтапного заполнения `segments` и materialize (см. **`3301_WALL_RENDERING_AND_STREAMING.md`**).
- **Стена — рендер:** много **`Sprite2D`** на видимой области остаётся основным потолком FPS при очень больших окнах; поток загрузки текстур не заменяет батч-отрисовку.

## Риски

- **Расхождение часов** между клиентами — некорректный выбор «победителя» при first-buyer policy.
- **Связность CubeView:** UI, выбор, покупка и sync сосредоточены в одном модуле — сложнее сопровождать и тестировать.
- **Тюнинг path / JSON библиотеки:** ошибки в шагах могут давать fail validate, smooth/fallback или труднопроходимые участки.
- **Брендинг:** в основном цветовая модель; расширение до полного material-набора — отдельная работа.

## Резюме техаудита (историческое)

- PathModel/bake — основной источник траектории платформ в `Level.gd` при **`use_path_leg_streaming == false`**; при **`true`** — **PathManager** и чанки в `chunks/`.
- Пул платформ, `WallData`/`PlatformDataStore` с merge, `WallRenderer` (видимая область + async текстуры) — согласованы с архитектурой 3301; актуальное описание — **`3301_WALL_RENDERING_AND_STREAMING.md`**.
- Рекомендованные направления: e2e sync, smoke CI, UX конфликтов — отражены в `3301_TODO_LIST.md`.
